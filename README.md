## MusicMani

MusicMani is a completely Java Digital Audio Workstation app, where users can upload any .wav audio file, modify the file's length, pitch or volume, and export it again. This app also allows for the blending of different files into a singular file, creating entirely new files that can be a mix of files that are individually modified.<br>
The UI of MusicMani is very easy-to-understand and use, with most controls widely known. The playhead (the triangle) on the timeline is where the app is while currently playing the audio, and is similar to slider in that it can be dragged.<br>
